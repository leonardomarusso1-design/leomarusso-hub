# Como instalar as skills do Hub

Cada pasta contém um `SKILL.md` independente. A skill é uma instrução de trabalho que você pode adicionar ao contexto do seu assistente de IA.

## Claude Code

Copie a pasta da skill escolhida para `.claude/skills/<nome-da-skill>/SKILL.md` no projeto em que deseja usar o método. Reabra a sessão e peça para o Claude aplicar a skill ao problema específico.

## Codex e outros agentes

Adicione o conteúdo do `SKILL.md` às instruções do projeto ou ao diretório de instruções customizadas aceito pela ferramenta. Mantenha o front matter `name` e `description` para facilitar descoberta.

## Como escolher

- `primeira-oferta-express`: transformar habilidade em oferta e abordagem.
- `mapa-de-trafego`: escolher canais e plano de aquisição.
- `copy-que-converte`: revisar mensagem, oferta e objeções.
- `funil-de-vendas-diagnostico`: decidir a próxima ação de uma conversa.
- `arquiteto-de-produto-ia`: escolher arquitetura e nível de IA.
- `growth-e-gestao-semanal`: revisar métricas e prioridades.
- `estrategista-de-conteudo`: criar pautas ligadas a objetivo comercial.
- `auditor-premium-e-seguranca`: revisar produto antes de publicar.
- `planejador-financeiro-pessoal`: organizar dinheiro e prioridades sem recomendação específica.

Use uma skill por vez, forneça contexto real e peça para o assistente declarar hipóteses quando os dados forem insuficientes.
